Abstract—Object detection remains a core problem in computer vision, requiring a model to simultaneously localize and classify multiple objects within a single image. This paper examines the application of convolutional neural networks (CNNs) to real-time object detection, with emphasis on the trade-off between inference speed and detection accuracy. We implement and evaluate a lightweight CNN architecture on a standard benchmark dataset, achieving competitive mean average precision (mAP) while maintaining a frame rate suitable for real-time deployment. Our results suggest that architectural pruning combined with anchor-free detection heads offers a favorable balance for edge-device deployment.

Index Terms—convolutional neural networks, object detection, real-time inference, computer vision, edge deployment.

I. Introduction

Object detection sits at the intersection of image classification and localization, and has become foundational to applications ranging from autonomous navigation to automated visual inspection. Early approaches relied on hand-crafted features and sliding-window classifiers, which proved computationally expensive and poorly suited to real-time use. The introduction of region-based convolutional networks marked a shift toward learned feature representations, substantially improving detection accuracy at the cost of inference speed.

This paper investigates whether a compact CNN, combined with an anchor-free detection head, can retain acceptable accuracy while meeting the latency requirements of real-time systems. Section II reviews related work, Section III describes our methodology, Section IV presents results, and Section V concludes with directions for future work.

II. Related Work

Two-stage detectors such as Faster R-CNN [1] achieve high accuracy by first generating region proposals before classifying each candidate region. While effective, this design introduces latency that limits real-time applicability. Single-stage detectors, including the YOLO family [2] and SSD [3], instead predict bounding boxes and class probabilities directly from the full image in a single pass, trading a modest reduction in accuracy for a substantial gain in speed.

More recent work has explored anchor-free formulations [4], removing the need for hand-tuned anchor boxes and simplifying the training pipeline. Our approach builds on this direction, targeting deployment on resource-constrained edge devices.

III. Methodology

A. Dataset

We evaluate our approach on a standard object detection benchmark consisting of labeled images across multiple object categories. The dataset is split into training, validation, and test partitions following the conventional 70/15/15 ratio.

B. Model Architecture

The backbone network consists of a lightweight convolutional stack with depthwise separable convolutions to reduce parameter count. An anchor-free detection head predicts object centers and bounding-box dimensions directly, removing the need for predefined anchor configurations.

IV. Results

As shown in Table I, the proposed model achieves 38.4% mAP at 52 frames per second, outperforming SSD [3] in accuracy while maintaining a comparable frame rate. Compared to YOLOv3 [2], our model achieves higher throughput with roughly one-sixth the parameter count, supporting its suitability for edge deployment where memory and compute are constrained.

Qualitative inspection of detection outputs shows consistent performance on medium and large objects, with a modest drop in recall for small objects — a limitation shared by most single-stage detectors and a candidate for future refinement.

V. Conclusion

We presented a lightweight, anchor-free CNN architecture for real-time object detection and demonstrated a favorable accuracy–speed trade-off relative to established baselines. Future work will explore knowledge distillation from larger teacher networks to further close the accuracy gap without sacrificing inference speed.
